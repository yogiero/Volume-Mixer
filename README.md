# Volume Mixer

A lightweight Windows system-tray mixer for controlling master and per-app audio.

## Install

Download `VolumeMixerSetup.exe` from the latest release and run it.
The installer adds Volume Mixer to the notification area and can start it when you sign in.

## Features

- Master volume and mute controls
- Per-app volume and mute controls
- App icons and direct access to app windows
- Persistent app exclusions

## Requirements

Windows 10 or Windows 11.
